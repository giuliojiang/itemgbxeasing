Preview is driven by IR, not raw mover. Real mesh if found, else proxy icosahedron.
How it works: Item.Gbx is LZO compressed. We decompress, find CPlugAnimLocSimple mover, convert to IR JSON with property: translation|rotation, axis x|y|z, from/to, durationMs, easing, loop. You (or an AI) edit the JSON, press Check to validate + preview on the real mesh, then Export. Export writes a BUUR file (uncompressed body) – Trackmania loads it fine.

Item Move Studio – Help

  1. Load your .Item.Gbx – we show IR JSON and try to show real mesh.
  2. Copy IR to ChatGPT/Claude: “make it float higher and spin faster, keep schema”.
  3. Paste edited JSON back, click Check + Preview – we validate and animate the real model.
  4. Export – downloads *_mod.Item.Gbx (BUUR).
IR schema: irVersion:1, animations:[{property, axis x|y|z, from, to, durationMs, delayMs, easing linear|easeInOut|spring|bounce, loop restart|pingPong}], composition.mode parallel|sequence. Bake: max duration per property → RotPeriod/TransPeriod, max |to-from| → TransY, first rot delta → RotAngle.
Mesh: heuristic vertex block scan. If it fails we show proxy but mover still works. Future: full CPlugCrystal parser.
