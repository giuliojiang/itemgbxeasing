What am I editing?
Drop a file to see. Your item has a tiny hidden box called CPlugAnimLocSimple with 9 numbers: how fast it spins (RotPeriod), how much it floats (TransY), which axis, etc. We make that friendly with sliders. The game loops those forever – so chaining is simulated by baking your blocks into one loop.
How chaining works (like web UI)
In web animations you do element.animate([...], {duration, easing}) and combine with Promise.all([anim1, anim2]) for parallel or await anim1.finished; anim2.play() for sequence. Here we do the same: each block is an interpolation with from → to, duration, easing. Parallel = add their transforms, Sequence = offset start by previous duration. Bake = compress to the single GBX oscillator.

How to use Item Move Studio

  1. Drop your .Item.Gbx – big box top-left. Everything stays in your browser, no upload.
  2. Pick a Quick Start – ☁️ Gentle float, 🌀 Spin, 🛸 Orbit+float, 🔔 Pendulum. One click sets sensible numbers.
  3. Tweak with sliders – ↕️ Float height, ⏱️ Float period (fast→slow), 🔄 Spin amount (shows ° too), Axis Y=carousel X=tumble Z=roll. Preview on the right moves live.
  4. Chain like web animations – Add Float / Spin blocks. Each is a keyframe from → to with duration & easing (linear=constant, ease in-out=smooth, spring=bouncy). Blend: Parallel = both at once (like Promise.all), Sequence = one after another.
  5. Watch the 3D – The balloon simulates your exact GBX mover (RotPeriod, TransPeriod, TransY...). Pause / Reset view top-right. FPS shows smoothness.
  6. Save – Blue button saves BUUR uncompressed .Item.Gbx – Trackmania loads it. Keep original as backup.
Tip: Your item has a hidden CPlugAnimLocSimple with 9 numbers. We make it friendly. Chaining is baked to that single loop for the game, but you see the chain blended in preview.

Easing = same as CSS animation-timing-function. The timeline bars below the 3D view stretch by duration so you see the chain.
